# Question 11 — Yanbu Recycling Weekly Goal

**Topic:** for

## Problem statement
Read seven nonnegative daily counts of collected bottles. Print their total and whether the fictional weekly target of 100 is reached.

## Requirements
- Use for and simple Java statements.
- Read input through `Scanner` and follow the exact output requirements.
- Handle boundary cases as described.
- Avoid arrays, files, and user-defined methods.

## Sample input
```text
10 15 20 10 15 20 10
```

## Expected output
```text
Total: 100
Goal reached
```

## Additional tests
Seven zeros gives 0 and Goal not reached; a negative entry is Invalid count.
