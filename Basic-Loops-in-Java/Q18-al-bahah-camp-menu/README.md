# Question 18 — Al Bahah Camp Menu

**Topic:** do-while

## Problem statement
Create a fictional camp activity menu. Code 1 prints Hiking, 2 prints Camping, 3 prints Safety briefing, and 0 prints Goodbye and terminates. Invalid choices do not end the loop.

## Requirements
- Use do-while and simple Java statements.
- Read input through `Scanner` and follow the exact output requirements.
- Handle boundary cases as described.
- Avoid arrays, files, and user-defined methods.

## Sample input
```text
2
3
0
```

## Expected output
```text
Camping
Safety briefing
Goodbye
```

## Additional tests
0 prints Goodbye; 9 then 0 prints Invalid choice, Goodbye.
