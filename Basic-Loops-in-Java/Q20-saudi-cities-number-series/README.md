# Question 20 — Saudi Cities Number Series

**Loop focus:** for + continue

## Programming problem
A Saudi geography club numbers study cards from 1 to N. Read N between 1 and 30. Use a for loop with continue to skip multiples of 4, printing all remaining numbers on one line with single spaces.

## Requirements
- Use the specified loop type and console input/output.
- Do not use arrays, files or user-defined methods.
- Validate the given input limits.
- Match the required output formatting.

## Sample input
```text
10
```

## Expected output
```text
1 2 3 5 6 7 9 10
```

## Additional tests
1 gives 1; 4 gives 1 2 3; 0 gives Invalid limit.
