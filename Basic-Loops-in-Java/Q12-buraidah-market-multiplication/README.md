# Question 12 — Buraidah Market Multiplication

**Topic:** for

## Problem statement
Read an integer 1–12. Display the first five multiples of that number using a for loop with the exact 'N x i = product' layout.

## Requirements
- Use for and simple Java statements.
- Read input through `Scanner` and follow the exact output requirements.
- Handle boundary cases as described.
- Avoid arrays, files, and user-defined methods.

## Sample input
```text
3
```

## Expected output
```text
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
3 x 4 = 12
3 x 5 = 15
```

## Additional tests
1 prints the first five multiples; 0 is Invalid number.
