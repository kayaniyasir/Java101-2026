# Question 16 — Najran Pattern Pyramid

**Topic:** nested for

## Problem statement
Read N between 1 and 5. Use nested for loops to print a right-aligned staircase of hashes; the first line contains N-1 spaces and one hash, and the final line contains N hashes.

## Requirements
- Use nested for and simple Java statements.
- Read input through `Scanner` and follow the exact output requirements.
- Handle boundary cases as described.
- Avoid arrays, files, and user-defined methods.

## Sample input
```text
3
```

## Expected output
```text
  #
 ##
###
```

## Additional tests
1 gives #; 6 gives Invalid height.
