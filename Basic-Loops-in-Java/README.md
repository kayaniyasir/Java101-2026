# Basic Loops in Java

**20 Saudi-themed programming questions with separate Java solutions**

A standalone practice collection inside Java101-2026. Developed for students studying basic Java loops: `for`, `while`, `do-while`, nested loops, `break`, and `continue`.

## How to use
1. Select a question below.
2. Read the scenario and test cases in its `README.md`.
3. Write your own Java solution before opening the supplied `.java` file.
4. Compile and run your program, then test the boundary cases.

## Compile and run
Open the question's folder, then:

```bash
javac LoopQuestion01.java
java LoopQuestion01
```

Use the matching class name for other questions. Requires an installed Java Development Kit (JDK). No arrays, user-defined methods, files, or exception handling are required in the exercises.

## Notes
- Saudi city references are learning scenarios, not claims about real prices, policies or events.
