# Question 19 — Makkah Conference Seat Rows

**Loop focus:** nested for

## Programming problem
A fictional conference arranges R rows and C chairs per row. Read integers R and C between 1 and 5. Using nested loops, print seat numbers 1 through C on every row, separating numbers with single spaces.

## Requirements
- Use the specified loop type and console input/output.
- Do not use arrays, files or user-defined methods.
- Validate the given input limits.
- Match the required output formatting.

## Sample input
```text
2 3
```

## Expected output
```text
1 2 3
1 2 3
```

## Additional tests
1 1 gives 1; dimensions outside 1–5 give Invalid dimensions.
