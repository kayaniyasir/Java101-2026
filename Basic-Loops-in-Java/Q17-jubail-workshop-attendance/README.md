# Question 17 — Jubail Workshop Attendance

**Topic:** for

## Problem statement
Read N (1–30), then N attendance status values (1 = present, 0 = absent). Use a for loop to count present students. If any status is not 0 or 1, print Invalid status.

## Requirements
- Use for and simple Java statements.
- Read input through `Scanner` and follow the exact output requirements.
- Handle boundary cases as described.
- Avoid arrays, files, and user-defined methods.

## Sample input
```text
5
1 0 1 1 0
```

## Expected output
```text
Present: 3
```

## Additional tests
All absent -> Present: 0; any 2 -> Invalid status.
