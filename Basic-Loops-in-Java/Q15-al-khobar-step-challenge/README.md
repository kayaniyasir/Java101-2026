# Question 15 — Al Khobar Step Challenge

**Topic:** while

## Problem statement
Read a series of daily nonnegative step counts; 0 ends the input. Print how many days were recorded and the total steps. Any negative count is invalid.

## Requirements
- Use while and simple Java statements.
- Read input through `Scanner` and follow the exact output requirements.
- Handle boundary cases as described.
- Avoid arrays, files, and user-defined methods.

## Sample input
```text
4000
5000
0
```

## Expected output
```text
Days: 2
Steps: 9000
```

## Additional tests
0 immediately yields zero days and steps; negative count produces Invalid steps.
