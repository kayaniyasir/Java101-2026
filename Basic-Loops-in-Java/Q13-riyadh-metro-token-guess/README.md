# Question 13 — Riyadh Metro Token Guess

**Topic:** while + break

## Problem statement
A fictional token game has the secret number 7. Read up to five guesses. Stop early when correct. Print Correct! for success or No more attempts after five wrong guesses.

## Requirements
- Use while + break and simple Java statements.
- Read input through `Scanner` and follow the exact output requirements.
- Handle boundary cases as described.
- Avoid arrays, files, and user-defined methods.

## Sample input
```text
3
7
```

## Expected output
```text
Correct!
```

## Additional tests
7 as the first guess wins immediately; five incorrect guesses end the game.
