# Question 24 — Buraidah Price File Total

**Skill:** file and totals

## KSA-themed task
Read whole-number prices from prices.txt and print their sum.

## Important instructions
- **Read from** the supplied `prices.txt` using `Scanner` and `File`.
- Keep the sample file in the working directory when you run Java.
- Use beginner Java file reading, conditions and loops; close the file scanner.
- The main method declares `throws FileNotFoundException` rather than using try/catch.
- **Boundary cases:** Empty file→total 0; any negative price→Invalid price.

## Sample file contents: prices.txt
```text
12
8
5
```

## Expected output
```text
Total: SAR 25
```
