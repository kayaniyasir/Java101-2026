# Question 10 — Madinah Book Fair Eligibility

**Focus:** boolean with two parameters

## Problem
At a fictional Madinah reading competition, applicants must be 12–18 inclusive and have read at least three books. Read age and number of books. Write eligible(int age,int books).

## Requirements
- Define and call the requested **static method** from `main`.
- Use `Scanner` for inputs where required. Use basic Java only.
- No arrays, files, collections, exceptions or recursion.
- Match the expected output and validate input where specified.

## Sample input
```text
15 4
```

## Sample output
```text
Eligible
```

## Boundary and additional tests
12 3 -> Eligible; 18 2 -> Not eligible; negative -> Invalid input.
