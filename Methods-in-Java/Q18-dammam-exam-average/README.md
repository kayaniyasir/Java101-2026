# Question 18 — Dammam Exam Average

**Focus:** method with three arguments

## Problem
Read three exam marks in the inclusive range 0–100. Write average(double a,double b,double c) returning their mean.

## Requirements
- Write and call the specified static method(s).
- Use basic Java, `Scanner`, and methods as described.
- No arrays, files, collections, exception handling or recursion.
- Match output exactly; reject invalid input when required.

## Sample input
```text
80 90 100
```

## Sample output
```text
Average: 90.00
```

## Boundary tests
All 0 -> 0.00; any 101 -> Invalid marks.
