# Question 12 — Jazan Mango Box Price

**Focus:** method with parameters

## Problem
Read the number of mango boxes (0–100) and price per box (0–1000). Write calculateTotal(int count,double price).

## Requirements
- Write and call the specified static method(s).
- Use basic Java, `Scanner`, and methods as described.
- No arrays, files, collections, exception handling or recursion.
- Match output exactly; reject invalid input when required.

## Sample input
```text
3 12.5
```

## Sample output
```text
Total: SAR 37.50
```

## Boundary tests
0 12.5 -> 0.00; negative -> Invalid input.
