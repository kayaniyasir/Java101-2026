# Question 08 — Yanbu Water Bottles

**Focus:** two int parameters

## Problem
A Yanbu school distributes water bottles equally among groups. Read number of groups and bottles per group (both 0–100). Write totalBottles(int groups,int perGroup) returning the product.

## Requirements
- Define and call the requested **static method** from `main`.
- Use `Scanner` for inputs where required. Use basic Java only.
- No arrays, files, collections, exceptions or recursion.
- Match the expected output and validate input where specified.

## Sample input
```text
4 6
```

## Sample output
```text
Bottles needed: 24
```

## Boundary and additional tests
0 6 -> 0; negative -> Invalid input.
