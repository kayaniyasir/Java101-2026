# Question 07 — Hail Student Grade

**Focus:** return String

## Problem
Read an exam mark from 0 to 100. Write grade(int mark), returning Excellent for 90–100, Good for 70–89 and Needs improvement otherwise.

## Requirements
- Define and call the requested **static method** from `main`.
- Use `Scanner` for inputs where required. Use basic Java only.
- No arrays, files, collections, exceptions or recursion.
- Match the expected output and validate input where specified.

## Sample input
```text
85
```

## Sample output
```text
Good
```

## Boundary and additional tests
90 -> Excellent; 69 -> Needs improvement; 101 -> Invalid mark.
