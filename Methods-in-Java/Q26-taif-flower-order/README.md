# Question 26 — Taif Flower Order

**Focus:** multiple methods

## Problem
A Taif shop sells bouquets for fictional SAR 25 each with SAR 10 fixed delivery. Read bouquet quantity (0–50). Write bouquetCost(int qty), deliveryFee() and totalCost(int qty) that calls both.

## Requirements
- Write and call the specified static method(s).
- Use `Scanner` where needed, with beginner Java concepts.
- No arrays, files, collections, exception handling or recursion.
- Validate the specified input range and use exact output formatting.

## Sample input
```text
3
```

## Sample output
```text
Order total: SAR 85
```

## Boundary tests
0 → SAR 10; 51 → Invalid quantity.

javac MethodQuestion26.java
