# Question 09 — Buraidah Date Harvest

**Focus:** return double

## Problem
Read the harvested date weight in kg (0–10000). Write saleValue(double kg), returning value at fictional SAR 12.50 per kg. Print two decimal places.

## Requirements
- Define and call the requested **static method** from `main`.
- Use `Scanner` for inputs where required. Use basic Java only.
- No arrays, files, collections, exceptions or recursion.
- Match the expected output and validate input where specified.

## Sample input
```text
8
```

## Sample output
```text
Value: SAR 100.00
```

## Boundary and additional tests
0 -> 0.00; -5 -> Invalid weight.
