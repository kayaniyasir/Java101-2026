# Question 04 — Taif Fruit Packing

**Focus:** return int, parameters

## Problem
A Taif farm packs fruit into baskets of four. Read a nonnegative fruit count (at most 1000). Write fullBaskets(int fruit) returning the number of complete baskets.

## Requirements
- Define and call the requested **static method** from `main`.
- Use `Scanner` for inputs where required. Use basic Java only.
- No arrays, files, collections, exceptions or recursion.
- Match the expected output and validate input where specified.

## Sample input
```text
18
```

## Sample output
```text
Full baskets: 4
```

## Boundary and additional tests
0 -> 0; 3 -> 0; negative -> Invalid fruit count.
