# Question 15 — Diriyah Museum Hours

**Focus:** boolean method

## Problem
Read visitor arrival hour in 24-hour format (0–23). A fictional museum opens from 9:00 inclusive to 17:00 exclusive. Implement isOpen(int hour).

## Requirements
- Write and call the specified static method(s).
- Use basic Java, `Scanner`, and methods as described.
- No arrays, files, collections, exception handling or recursion.
- Match output exactly; reject invalid input when required.

## Sample input
```text
16
```

## Sample output
```text
Open
```

## Boundary tests
9 -> Open; 17 -> Closed; 24 -> Invalid hour.
