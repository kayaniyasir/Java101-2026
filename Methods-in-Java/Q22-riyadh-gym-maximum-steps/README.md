# Question 22 — Riyadh Gym Maximum Steps

**Focus:** return int

## Problem
Read step counts of two participants (0–100000). Write maxSteps(int a,int b) returning the greater.

## Requirements
- Write and call the specified static method(s).
- Use `Scanner` where needed, with beginner Java concepts.
- No arrays, files, collections, exception handling or recursion.
- Validate the specified input range and use exact output formatting.

## Sample input
```text
7500 9000
```

## Sample output
```text
Maximum steps: 9000
```

## Boundary tests
Equal counts return either same count; negative → Invalid steps.
