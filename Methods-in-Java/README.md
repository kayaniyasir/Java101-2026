# Methods in Java

**30 KSA-themed Java programming exercises, each in a separate folder with its own problem statement and complete solution.**

This collection is designed for students learning **Chapter 6: Methods** in introductory Java programming. Students move from basic no-argument `void` methods to parameters, return values, Boolean methods, method calls, method overloading and local scope. The activities use familiar Saudi city contexts and fictional situations rather than real prices or policies.

## Learning objectives
- Declare and invoke `static` methods from `main`.
- Distinguish `void` methods from methods returning `int`, `double`, `boolean` or `String`.
- Pass arguments into parameters and use return values in calculations.
- Break a larger problem into cooperating methods.
- Practice simple overloading and local variable scope.
- Apply input validation and sample/boundary testing.

## How to study
1. Click a question link and read its `README.md`.
2. Design the required method signature before coding.
3. Write your own solution, call the method from `main`, and compare output with the examples.
4. Test boundary conditions; then compare against the supplied `MethodQuestionNN.java`.

## Compiling and running
Open the relevant question folder and use the matching number, e.g.:

```bash
javac MethodQuestion01.java
java MethodQuestion01
```

No arrays, collections, file handling, exception handling or recursion are needed in these exercises. A Java Development Kit is required.
