# Question 23 — Qassim Farmers Even Crates

**Focus:** boolean method, loop

## Problem
Read number of crate labels N (1–20). Implement isEven(int n). From main, loop through labels 1 to N and print only even labels separated by a space.

## Requirements
- Write and call the specified static method(s).
- Use `Scanner` where needed, with beginner Java concepts.
- No arrays, files, collections, exception handling or recursion.
- Validate the specified input range and use exact output formatting.

## Sample input
```text
8
```

## Sample output
```text
2 4 6 8
```

## Boundary tests
1 produces a blank line; 2 gives 2; 0 → Invalid limit.
