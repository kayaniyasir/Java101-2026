# Question 25 — Jeddah Coffee Reward

**Focus:** return boolean

## Problem
A fictional Jeddah cafe gives a free drink after 10 purchased drinks. Read a nonnegative purchase count (0–100). Implement hasReward(int count).

## Requirements
- Write and call the specified static method(s).
- Use `Scanner` where needed, with beginner Java concepts.
- No arrays, files, collections, exception handling or recursion.
- Validate the specified input range and use exact output formatting.

## Sample input
```text
10
```

## Sample output
```text
Reward available
```

## Boundary tests
9 → No reward; 10 → Reward available; -1 → Invalid count.
