# Question 30 — Saudi School Report Generator

**Focus:** scope and method calls

## Problem
Read three student marks from 0 to 100. Write max(int a,int b) returning the larger value, bestOfThree(int a,int b,int c) which calls max twice, and showResult(int score) to print the highest mark. Demonstrate local variable scope and method composition.

## Requirements
- Write and call the specified static method(s).
- Use `Scanner` where needed, with beginner Java concepts.
- No arrays, files, collections, exception handling or recursion.
- Validate the specified input range and use exact output formatting.

## Sample input
```text
70 85 78
```

## Sample output
```text
Highest mark: 85
```

## Boundary tests
All 0 → 0; all 100 → 100; invalid mark → Invalid marks.
