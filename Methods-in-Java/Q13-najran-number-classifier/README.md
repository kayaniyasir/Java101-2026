# Question 13 — Najran Number Classifier

**Focus:** return String

## Problem
Read an integer. Write describe(int n) returning Positive, Negative or Zero.

## Requirements
- Write and call the specified static method(s).
- Use basic Java, `Scanner`, and methods as described.
- No arrays, files, collections, exception handling or recursion.
- Match output exactly; reject invalid input when required.

## Sample input
```text
-8
```

## Sample output
```text
Negative
```

## Boundary tests
0 -> Zero; 4 -> Positive.
