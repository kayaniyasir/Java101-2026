# Question 05 — Abha Temperature Checker

**Focus:** boolean method

## Problem
Read an integer temperature. Write isCool(int temp), returning true if temperature is 20°C or less. Print Cool day or Warm day.

## Requirements
- Define and call the requested **static method** from `main`.
- Use `Scanner` for inputs where required. Use basic Java only.
- No arrays, files, collections, exceptions or recursion.
- Match the expected output and validate input where specified.

## Sample input
```text
19
```

## Sample output
```text
Cool day
```

## Boundary and additional tests
20 -> Cool day; 21 -> Warm day.
