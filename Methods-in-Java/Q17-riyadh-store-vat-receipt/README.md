# Question 17 — Riyadh Store VAT Receipt

**Focus:** method composition

## Problem
At a fictional store, read subtotal (0–100000). Implement vat(double amount) returning 15% VAT and grandTotal(double amount) calling vat. Print total to two decimals.

## Requirements
- Write and call the specified static method(s).
- Use basic Java, `Scanner`, and methods as described.
- No arrays, files, collections, exception handling or recursion.
- Match output exactly; reject invalid input when required.

## Sample input
```text
200
```

## Sample output
```text
Total with VAT: SAR 230.00
```

## Boundary tests
0 -> 0.00; -1 -> Invalid subtotal.
