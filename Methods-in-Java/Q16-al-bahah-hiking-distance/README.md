# Question 16 — Al Bahah Hiking Distance

**Focus:** return double

## Problem
Read hours walked (0–24) and average speed (0–10 km/h). Write distance(double hours,double speed) returning total kilometers.

## Requirements
- Write and call the specified static method(s).
- Use basic Java, `Scanner`, and methods as described.
- No arrays, files, collections, exception handling or recursion.
- Match output exactly; reject invalid input when required.

## Sample input
```text
2 3.5
```

## Sample output
```text
Distance: 7.0 km
```

## Boundary tests
