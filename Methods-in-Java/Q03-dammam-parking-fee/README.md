# Question 03 — Dammam Parking Fee

**Focus:** return int

## Problem
Read the number of parking hours (0–12). A fictional parking lot charges SAR 5 per hour. Write fee(int hours) returning the total, then print it. Reject out-of-range hours.

## Requirements
- Define and call the requested **static method** from `main`.
- Use `Scanner` for inputs where required. Use basic Java only.
- No arrays, files, collections, exceptions or recursion.
- Match the expected output and validate input where specified.

## Sample input
```text
3
```

## Sample output
```text
Parking fee: SAR 15
```

## Boundary and additional tests
0 -> SAR 0; 13 -> Invalid hours.

javac MethodQuestion03.java
