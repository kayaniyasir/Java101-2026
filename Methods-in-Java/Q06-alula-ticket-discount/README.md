# Question 06 — AlUla Ticket Discount

**Focus:** return double

## Problem
An AlUla museum practice scenario has fictional admission SAR 40. Read the visitor age. Write ticketPrice(int age): ages under 12 pay half, others full. Negative ages are invalid.

## Requirements
- Define and call the requested **static method** from `main`.
- Use `Scanner` for inputs where required. Use basic Java only.
- No arrays, files, collections, exceptions or recursion.
- Match the expected output and validate input where specified.

## Sample input
```text
10
```

## Sample output
```text
Ticket: SAR 20.00
```

## Boundary and additional tests
11 -> 20.00; 12 -> 40.00; -1 -> Invalid age.
