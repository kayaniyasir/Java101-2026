# Question 20 — Makkah Conference Badges

**Focus:** void method called in a loop

## Problem
Read attendee count (1–10). Write printBadge(int number), which prints Attendee #N. Call it using a for loop in main for every attendee.

## Requirements
- Write and call the specified static method(s).
- Use basic Java, `Scanner`, and methods as described.
- No arrays, files, collections, exception handling or recursion.
- Match output exactly; reject invalid input when required.

## Sample input
```text
3
```

## Sample output
```text
Attendee #1
Attendee #2
Attendee #3
```

## Boundary tests
1 -> Attendee #1; 11 -> Invalid count.
