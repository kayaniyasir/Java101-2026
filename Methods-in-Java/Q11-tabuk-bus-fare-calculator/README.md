# Question 11 — Tabuk Bus Fare Calculator

**Focus:** return value

## Problem
Read passenger count (0–50). Write busFare(int passengers) returning the fictional SAR 7 fare per passenger.

## Requirements
- Write and call the specified static method(s).
- Use basic Java, `Scanner`, and methods as described.
- No arrays, files, collections, exception handling or recursion.
- Match output exactly; reject invalid input when required.

## Sample input
```text
5
```

## Sample output
```text
Fare: SAR 35
```

## Boundary tests
0 -> 0; 51 -> Invalid passengers.
