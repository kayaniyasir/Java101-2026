# Question 02 — Jeddah Visitor Greeting

**Focus:** void parameter

## Problem
Read one visitor's first name and pass it to a void method greet(String name), which prints a Jeddah welcome.

## Requirements
- Define and call the requested **static method** from `main`.
- Use `Scanner` for inputs where required. Use basic Java only.
- No arrays, files, collections, exceptions or recursion.
- Match the expected output and validate input where specified.

## Sample input
```text
Sara
```

## Sample output
```text
Welcome to Jeddah, Sara!
```

## Boundary and additional tests
Read a single word as the name.
