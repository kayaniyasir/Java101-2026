# Question 01 — Riyadh Welcome Message

**Focus:** void method

## Problem
Create a no-argument void method named welcome that prints a greeting for a Riyadh coding event. Call it twice from main.

## Requirements
- Define and call the requested **static method** from `main`.
- Use `Scanner` for inputs where required. Use basic Java only.
- No arrays, files, collections, exceptions or recursion.
- Match the expected output and validate input where specified.

## Sample input
```text
(no input)
```

## Sample output
```text
Welcome to Riyadh Coding Day!
Welcome to Riyadh Coding Day!
```

## Boundary and additional tests
Method must contain the print statement.

javac MethodQuestion01.java
