# Question 17 — Riyadh VAT Calculator

**Main concept:** named constant

## KSA-themed programming problem
Calculate fictional VAT at 15% of a purchase subtotal using a final constant.

## Important points
- **Use named constant** in your solution.
- **Limits and boundary tests:** Subtotal 0–100000. Declare final double VAT_RATE = 0.15.
- Read the input using `Scanner` and print exactly the shown output.
- Avoid arrays, custom methods, files, and advanced Java features.

## Sample input
```text
200
```

## Expected output
```text
VAT: SAR 30.00
Total: SAR 230.00
```

## Additional testing
Check the lower and upper boundaries, invalid inputs, and values that produce decimal results.
