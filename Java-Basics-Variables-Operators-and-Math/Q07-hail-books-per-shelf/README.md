# Question 07 — Hail Books per Shelf

**Main concept:** integer division

## KSA-themed task
Read the number of books and the number of shelves. Divide evenly and display whole books per shelf.

## Input
Enter the values shown in the sample, in the same order.

## Important rules
- **Focus:** integer division.
- **Input validation:** Books 0–1000; shelves 1–100. Ignore the remainder for this question.
- **Output:** Follow the exact text and number formatting shown below.
- Use variables, basic operators and `Scanner`; do not use arrays, custom methods or files.

## Sample input
```text
23 5
```

## Expected output
```text
Books per shelf: 4
```

## Test suggestions
Test the smallest and largest valid inputs, zero when allowed, and an invalid value. Compare the output carefully.
