# Question 06 — AlUla Ticket Change

**Main concept:** subtraction

## KSA-themed task
A visitor pays cash for a fictional exhibition ticket. Calculate change.

## Input
Enter the values shown in the sample, in the same order.

## Important rules
- **Focus:** subtraction.
- **Input validation:** Input cash and ticket price from 0–1000; cash must cover ticket price.
- **Output:** Follow the exact text and number formatting shown below.
- Use variables, basic operators and `Scanner`; do not use arrays, custom methods or files.

## Sample input
```text
100 35
```

## Expected output
```text
Change: SAR 65.00
```

## Test suggestions
Test the smallest and largest valid inputs, zero when allowed, and an invalid value. Compare the output carefully.
