# Question 21 — Riyadh Round Trip Distance

**Main concept:** Math.abs

## KSA-themed problem

## Important rules
- **Main skill:** Math.abs.
- **Input limits / boundary tests:** Value -10000 to 10000; negative becomes positive.
- Print the expected message and numeric formatting exactly as shown.
- Use Java variables, operators, `Math` functions and `Scanner`. No arrays or file handling.

## Sample input


## Expected output
```text
Distance magnitude: 12 km
```
