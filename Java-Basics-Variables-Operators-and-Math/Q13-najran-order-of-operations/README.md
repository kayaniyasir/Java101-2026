# Question 13 — Najran Order of Operations

**Main concept:** operator precedence

## KSA-themed programming problem
Read three integers a, b, and c; calculate a + b × c and (a + b) × c separately.

## Important points
- **Use operator precedence** in your solution.
- **Limits and boundary tests:** Inputs between -100 and 100. Multiplication precedes addition.
- Read the input using `Scanner` and print exactly the shown output.
- Avoid arrays, custom methods, files, and advanced Java features.

## Sample input
```text
2 3 4
```

## Expected output
```text
Without parentheses: 14
With parentheses: 20
```

## Additional testing
Check the lower and upper boundaries, invalid inputs, and values that produce decimal results.
