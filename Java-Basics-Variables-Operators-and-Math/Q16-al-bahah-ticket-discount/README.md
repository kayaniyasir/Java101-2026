# Question 16 — Al Bahah Ticket Discount

**Main concept:** compound assignment

## KSA-themed programming problem
Read a fictional ticket price. Subtract 10 SAR using compound assignment and display the result.

## Important points
- **Use compound assignment** in your solution.
- **Limits and boundary tests:** Ticket price 10–1000; use -= 10.
- Read the input using `Scanner` and print exactly the shown output.
- Avoid arrays, custom methods, files, and advanced Java features.

## Sample input
```text
50
```

## Expected output
```text
Discounted: SAR 40.00
```

## Additional testing
Check the lower and upper boundaries, invalid inputs, and values that produce decimal results.
