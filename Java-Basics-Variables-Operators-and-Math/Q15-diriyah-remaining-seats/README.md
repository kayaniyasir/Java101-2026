# Question 15 — Diriyah Remaining Seats

**Main concept:** decrement operator

## KSA-themed programming problem
Read the number of free seats; reserve one seat and show the remaining count.

## Important points
- **Use decrement operator** in your solution.
- **Limits and boundary tests:** Initial seats 1–500; zero must print Invalid seats.
- Read the input using `Scanner` and print exactly the shown output.


## Expected output
```text
Remaining seats: 4
```
