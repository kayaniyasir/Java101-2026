# Question 09 — Buraidah Three-Day Average

**Main concept:** floating point division

## KSA-themed task
Read whole-number sales for three days. Print their average to two decimal places.

## Input
Enter the values shown in the sample, in the same order.

## Important rules
- **Focus:** floating point division.
- **Input validation:** Each daily sale 0–10000; use 3.0 or a double cast.
- **Output:** Follow the exact text and number formatting shown below.
- Use variables, basic operators and `Scanner`; do not use arrays, custom methods or files.

## Sample input
```text
10 20 25
```

## Expected output
```text
Average: 18.33
```

## Test suggestions
Test the smallest and largest valid inputs, zero when allowed, and an invalid value. Compare the output carefully.
