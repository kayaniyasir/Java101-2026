# Question 30 — Saudi Event Budget Summary

**Main concept:** combined arithmetic and Math

## KSA-themed problem
Read a fictional event budget, spending, and expected guest count. Calculate remaining budget and budget per guest. Print remaining with two decimal places and per-guest amount rounded upward.

## Important rules
- **Main skill:** combined arithmetic and Math.
- **Input limits / boundary tests:** Budget and spent 0–100000; spent ≤budget; guests 1–1000; use Math.ceil.
- Print the expected message and numeric formatting exactly as shown.
- Use Java variables, operators, `Math` functions and `Scanner`. No arrays or file handling.

## Sample input
```text
1000 650 20
```

## Expected output
```text
Remaining: SAR 350.00
Per guest: SAR 18
```

## Additional testing
Test the stated boundaries and at least one invalid input. Check rounding and data types carefully.
