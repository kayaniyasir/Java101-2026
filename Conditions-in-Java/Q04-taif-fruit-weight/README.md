# Question 04 — Taif Fruit Weight

**Topic:** if-else

## Scenario
A Taif fruit seller calls a basket heavy when its weight reaches 10 kg.

## Your task
Read weight as a double from 0 to 100 kg.

### Important rules
Print **Heavy basket** for weight 10 or above; otherwise **Light basket**.

**Remember:** Check the boundary values carefully and print exactly the expected messages.

## Sample input
```text
9.5
```

## Expected output
```text
Light basket
```

## Important test cases
10 → Heavy basket; 0 → Light basket; -1 → Invalid weight.
