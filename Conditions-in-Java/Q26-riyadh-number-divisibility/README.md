# Question 26 — Riyadh Number Divisibility

**Core skill:** combined logical AND

## Story / scenario
A student tests whether a package identifier is divisible by both 3 and 5.

## What to do
Read an integer.

## Important rules (read carefully)
Print **Divisible by both** only if the number divides evenly by **3 AND 5**; otherwise **Not divisible by both**.

**Important:** Pay attention to `>=`, `<=`, `&&`, `||`, and whether the boundary is included. Use the indicated conditional structure.

## Sample input
```text
30
```

## Expected output
```text
Divisible by both
```

## Boundary cases to test
15→Divisible by both; 9→Not divisible by both; 0→Divisible by both.
