# Question 09 — Buraidah Scholarship Check

**Topic:** logical OR

## Scenario
A fictional student award considers a candidate eligible if they scored 90 or more **or** won a coding competition.

## Your task
Read score (0–100) and competition flag (1 = won, 0 = not won).

### Important rules
Print **Eligible** if either condition holds; otherwise **Not eligible**.

**Remember:** Check the boundary values carefully and print exactly the expected messages.

## Sample input
```text
85 1
```

## Expected output
```text
Eligible
```

## Important test cases
90 0 → Eligible; 89 0 → Not eligible; 101 0 → Invalid input.
