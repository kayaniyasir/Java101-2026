# Question 07 — Hail Even or Odd

**Topic:** modulo with if-else

## Scenario
A Hail coding event labels an integer as even or odd.

## Your task
Read any integer.

### Important rules
A number is **Even** when its remainder after dividing by 2 is zero; otherwise **Odd**.

**Remember:** Check the boundary values carefully and print exactly the expected messages.

## Sample input
```text
15
```

## Expected output
```text
Odd
```

## Important test cases
0 → Even; -4 → Even; -3 → Odd.
