# Question 18 — Hofuf Date Purchase VAT

**Concept:** if-else

## Scenario
A fictional Hofuf date shop uses a special practice rule: orders of SAR 100 or more receive SAR 10 off before 15% VAT.

## Input
Read subtotal (0–10000).

## Important rules
Apply **discount before VAT**. Print final total to two decimal places.

**Pay special attention:** Use the specified conditional statement, test boundary values and print exactly the required messages.

## Sample input
```text
100
```

## Expected output
```text
Total: SAR 103.50
```

## Boundary / extra tests
99 → 113.85; 100 → 103.50; -1 → Invalid amount.
