# Question 12 — Jazan Mango Quality Grade

**Concept:** if-else-if

## Scenario
A Jazan farm classifies mangoes using a quality score.

## Input
Read quality score 0–100.

## Important rules
**Premium** when score ≥90; **Good** when ≥70; **Regular** below 70.

**Pay special attention:** Use the specified conditional statement, test boundary values and print exactly the required messages.

## Sample input
```text
90
```

## Expected output
```text
Premium
```

## Boundary / extra tests
69 → Regular; 70 → Good; 89 → Good; 101 → Invalid score.
