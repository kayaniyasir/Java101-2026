# Question 11 — Tabuk Bus Seat Selection

**Concept:** switch

## Scenario
A fictional Tabuk bus offers three seat categories.

## Input
Read an integer code: 1 = Standard, 2 = Window, 3 = Premium.

## Important rules
Use a **switch** statement. Print the matching seat name; any other code prints **Invalid seat**.

**Pay special attention:** Use the specified conditional statement, test boundary values and print exactly the required messages.

## Sample input
```text
2
```

## Expected output
```text
Window
```

## Boundary / extra tests
1 → Standard; 3 → Premium; 0 → Invalid seat.
