# Question 01 — Riyadh School Pass Check

**Topic:** if-else

## Scenario
A school considers a student successful when their mark is at least 50.

## Your task
Read one integer mark between 0 and 100.

### Important rules
**Pass** if mark is 50 or higher; otherwise **Fail**. Reject invalid marks.

**Remember:** Check the boundary values carefully and print exactly the expected messages.

## Sample input
```text
50
```

## Expected output
```text
Pass
```

## Important test cases
49 → Fail; 100 → Pass; -1 → Invalid mark.
