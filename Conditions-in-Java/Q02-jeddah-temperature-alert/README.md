# Question 02 — Jeddah Temperature Alert

**Topic:** simple if

## Scenario
A Jeddah weather club alerts students when the temperature is unusually hot.

## Your task
Read one integer temperature in Celsius between -10 and 60.

### Important rules
Always print **Temperature recorded**. Also print **Heat alert** only if the value is 40 or higher.

**Remember:** Check the boundary values carefully and print exactly the expected messages.

## Sample input
```text
42
```

## Expected output
```text
Temperature recorded
Heat alert
```

## Important test cases
39 → only Temperature recorded; 40 → both lines; 61 → Invalid temperature.
