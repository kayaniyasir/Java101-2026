# Question 28 — Dammam Electricity Saving

**Core skill:** if-else

## Story / scenario
A fictional Dammam household is considered energy-saving if monthly electricity consumption is no more than 200 units.

## What to do
Read monthly units (0–5000).

## Important rules (read carefully)
Print **Saving** when units **≤200**, otherwise **High usage**.

**Important:** Pay attention to `>=`, `<=`, `&&`, `||`, and whether the boundary is included. Use the indicated conditional structure.

## Sample input
```text
200
```

## Expected output
```text
Saving
```

## Boundary cases to test
0→Saving; 201→High usage; -1→Invalid units.
