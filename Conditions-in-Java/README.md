# Conditions in Java — 30 KSA-Based Practice Questions

**30 independent Java exercises** with easy-to-follow problem statements, **highlighted important rules**, sample input/output, boundary tests, and individual complete Java solutions.

These exercises are for introductory programming students studying **selection statements (Chapter 3)**. Fictional scenarios use Saudi cities and familiar education, shopping, events, transport, weather and everyday decisions.

## Learning goals

By the end, you should be able to:

1. Write and understand `if`, `if-else` and `if-else-if` statements.
2. Decide when a **nested if** statement is appropriate.
3. Combine conditions with logical **AND (`&&`)** and **OR (`||`)**.
4. Use comparison operators `<`, `<=`, `>`, `>=`, `==` and `!=` correctly.
5. Use `switch` with integer, character and string choices.
6. Validate input and test **boundary values** such as 49 vs 50, 17 vs 18, and 99 vs 100.

## Suggested study order

- **Q01–Q07: Foundations.** Simple conditions, multiple branches, ranges and odd/even.
- **Q08–Q10: Logical operators and nested if.** Two conditions, `&&`, `||` and nested decisions.
- **Q11–Q20: Practical decisions.** `switch` menus, grouped tests, range checks, discounts and VAT.
- **Q21–Q30: Applied challenges.** Inclusive boundaries, grades, grouped switch cases, nested comparisons and scholarship rules.

## How to solve each question

1. Open its folder and read **Scenario**, **Input** and **Important rules**.
2. Identify which decision statement is appropriate.
3. Before writing code, check whether the minimum/maximum values are included.
4. Try the sample input and compare the exact output.
5. Try the boundary tests and invalid values.
6. Only then read the individual `ConditionQuestionNN.java` solution.

## Run any answer

Inside a question folder, compile and run with a Java Development Kit:

```bash
javac ConditionQuestion01.java
java ConditionQuestion01
```

Substitute the corresponding question number for other solutions. All solutions contain a complete `public static void main` and use `Scanner` for input. No arrays, files, user-written methods or exception handling are needed.
