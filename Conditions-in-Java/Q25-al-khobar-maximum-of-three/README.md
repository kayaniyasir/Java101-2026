# Question 25 — Al Khobar Maximum of Three

**Core skill:** nested if

## Story / scenario
A class compares three integer observations from an Al Khobar science fair.

## What to do
Read three integers.

## Important rules (read carefully)
Use **nested if** and comparisons to print **Largest: N**. Equal numbers are allowed.

**Important:** Pay attention to `>=`, `<=`, `&&`, `||`, and whether the boundary is included. Use the indicated conditional structure.

## Sample input
```text
8 12 7
```

## Expected output
```text
Largest: 12
```

## Boundary cases to test
5 5 5→Largest: 5; -5 -2 -7→Largest: -2.
