# Question 29 — Hail Weekend Sports Choice

**Core skill:** switch and validation

## Story / scenario
A fictional Hail school lets students select a sport using a number.

## What to do
Read an integer: 1 football, 2 basketball, 3 badminton, 4 swimming.

## Important rules (read carefully)
Use **switch** and print the sport's name; other numbers show **Invalid choice**.

**Important:** Pay attention to `>=`, `<=`, `&&`, `||`, and whether the boundary is included. Use the indicated conditional structure.

## Sample input
```text
3
```

## Expected output
```text
Badminton
```

## Boundary cases to test
1→Football; 4→Swimming; 5→Invalid choice.
