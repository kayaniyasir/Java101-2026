# Question 03 — Dammam Parking Eligibility

**Topic:** if-else

## Scenario
A fictional parking service offers a senior rate to drivers aged 60 or above.

## Your task
Read a driver's age between 0 and 120.

### Important rules
Show **Senior rate** for 60 or above; otherwise **Standard rate**.

**Remember:** Check the boundary values carefully and print exactly the expected messages.

## Sample input
```text
60
```

## Expected output
```text
Senior rate
```

## Important test cases
59 → Standard rate; 120 → Senior rate; -1 → Invalid age.
