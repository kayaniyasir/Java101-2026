# Question 13 — Najran Traffic Signal

**Concept:** switch with char

## Scenario
A Najran traffic exercise uses the first letters of traffic colors.

## Input
Read one letter: R, Y, or G (uppercase or lowercase).

## Important rules
Use **switch**: R→Stop, Y→Wait, G→Go; other letters→**Invalid signal**.

**Pay special attention:** Use the specified conditional statement, test boundary values and print exactly the required messages.

## Sample input
```text
g
```

## Expected output
```text
Go
```

## Boundary / extra tests
R → Stop; y → Wait; b → Invalid signal.
