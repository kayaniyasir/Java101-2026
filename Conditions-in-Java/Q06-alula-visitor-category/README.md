# Question 06 — AlUla Visitor Category

**Topic:** if-else-if ladder

## Scenario
A fictional AlUla exhibition sorts visitors into age groups.

## Your task
Read age between 0 and 120.

### Important rules
**Child** for 0–12, **Teen** for 13–17, **Adult** for 18–59, **Senior** for 60 or above.

**Remember:** Check the boundary values carefully and print exactly the expected messages.

## Sample input
```text
17
```

## Expected output
```text
Teen
```

## Important test cases
12 → Child; 18 → Adult; 59 → Adult; 60 → Senior; -1 → Invalid age.
