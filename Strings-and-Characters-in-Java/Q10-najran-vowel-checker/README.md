# Question 10 — Najran Vowel Checker

**Focus:** Character and if

## KSA-themed scenario
Read a single English letter and check whether it is a vowel (A,E,I,O,U), ignoring case.

## Important instructions
- **Read input using Scanner.** Each input token is separated by whitespace unless stated otherwise.
- **Use Character and if** as the main learning concept.
- **Match the exact output**, including capitalization and punctuation.
- **Test the important edge cases** before checking the answer.

## Sample input
```text
e
```

## Expected output
```text
Vowel
```

## Important test cases
b -> Consonant; E -> Vowel; ab -> Invalid letter; 3 -> Invalid letter.
