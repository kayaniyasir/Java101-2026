# Question 17 — Riyadh Clean Visitor Name

**Main skill:** trim()

## Scenario
Read a full line containing a visitor's name with possible leading or trailing spaces. Display it trimmed.

## Important rules
- **Use trim()** as the main programming concept.
- Read the sample input carefully: a full line may contain spaces.
- **Java String indices begin at zero.** Check any length requirement before using an index.
- Print the exact required message and validate input when specified.

## Sample input
```text
  Sara Ali  
```

## Expected output
```text
Name: Sara Ali
```

## Boundary tests
Input only spaces -> Invalid name; names with internal spaces stay intact.
