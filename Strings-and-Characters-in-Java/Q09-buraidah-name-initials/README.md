# Question 09 — Buraidah Name Initials

**Focus:** charAt()

## KSA-themed scenario
Read a student's first and last names (each one word). Print their initials as uppercase letters, separated by a dot.

## Important instructions
- **Read input using Scanner.** Each input token is separated by whitespace unless stated otherwise.
- **Use charAt()** as the main learning concept.
- **Match the exact output**, including capitalization and punctuation.
- **Test the important edge cases** before checking the answer.

## Sample input
```text
Sara Ali
```

## Expected output
```text
S.A
```

## Important test cases
ali hassan -> A.H; names must be nonempty tokens.
