# Question 20 — Sakaka Compare City Codes

**Main skill:** compareTo()

## Scenario
Read two uppercase city codes and decide which comes first alphabetically (lexicographic order).

## Important rules
- **Use compareTo()** as the main programming concept.
- Read the sample input carefully: a full line may contain spaces.
- **Java String indices begin at zero.** Check any length requirement before using an index.
- Print the exact required message and validate input when specified.

## Sample input
```text

```

## Expected output
```text
First code comes first
```

## Boundary tests
RUH ABH -> Second code comes first; RUH RUH -> Equal codes.
