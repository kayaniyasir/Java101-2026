# Question 01 — Riyadh Welcome Name

**Focus:** String input

## KSA-themed scenario
Read one student's first name (one word) and print a personalized greeting.

## Important instructions
- **Read input using Scanner.** Each input token is separated by whitespace unless stated otherwise.
- **Use String input** as the main learning concept.
- **Match the exact output**, including capitalization and punctuation.
- **Test the important edge cases** before checking the answer.

## Sample input
```text
Sara
```

## Expected output
```text
Welcome to Riyadh, Sara!
```

## Important test cases
