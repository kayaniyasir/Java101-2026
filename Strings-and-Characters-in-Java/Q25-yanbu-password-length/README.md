# Question 25 — Yanbu Password Length

**Main skill:** length and conditions

## KSA-themed problem
A fictional Yanbu portal requires passwords of at least 8 and at most 16 characters (no spaces). This exercise checks length only, not password strength.

## What your program must do
- Read the described input using `Scanner`.
- **Use length and conditions** along with loops or conditions when necessary.
- **Keep the output exactly as shown**, including punctuation and spacing.
- Check the **boundary cases** below before reading the solution.

## Sample input
```text
code1234
```

## Expected output
```text
Valid length
```

## Important test cases
1234567 -> Invalid length; 16 chars -> Valid length; 17 -> Invalid length.
