# Question 02 — Jeddah Daily Sales

**Main concept:** Sum of array elements

## Scenario
A Jeddah shop records its sales for several days. Calculate their total.

## What you need to do
N (1–7), followed by N nonnegative integer sales amounts (each 0–10000).

## Important points
- **Use a one-dimensional array** and the required operation.
- Use an int array and a loop to print Total sales: N.
- **Validate the input limits** before processing or printing results.
- Print exactly the messages shown, including spaces and capitalization.

## Sample input
```text
3
100 200 150
```

## Expected output
```text
Total sales: 450
```

## Boundary and extra tests
All zero sales; one day; negative sale.
