# Question 09 — Buraidah Date Boxes

**Main concept:** Reverse array output

## Scenario
A warehouse labels boxes in the order they are loaded; display them in reverse order.

## What you need to do
N (1–10), followed by N box IDs (1–9999).

## Important points
- **Use a one-dimensional array** and the required operation.
- Print elements **from the last index to the first**, separated by spaces.
- **Validate the input limits** before processing or printing results.
- Print exactly the messages shown, including spaces and capitalization.

## Sample input
```text
4
11 22 33 44
```

## Expected output
```text
44 33 22 11
```

## Boundary and extra tests
N=1; repeated IDs; ID zero invalid.
