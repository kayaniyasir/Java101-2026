# Question 08 — Yanbu Water Consumption

**Main concept:** Count a specific value

## Scenario
A Yanbu school records N students' daily water bottle counts.

## What you need to do
N (1–20), followed by N counts (0–10), then a target count (0–10).

## Important points
- **Use a one-dimensional array** and the required operation.
- Print the number of array values **equal to the target**.
- **Validate the input limits** before processing or printing results.
- Print exactly the messages shown, including spaces and capitalization.

## Sample input
```text
5
2 3 2 1 2
2
```

## Expected output
```text
Matches: 3
```

## Boundary and extra tests
Target absent; all match; target outside range.
