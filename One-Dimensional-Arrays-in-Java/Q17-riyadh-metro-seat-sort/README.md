# Question 17 — Riyadh Metro Seat Sort

**Main concept:** Sort ascending

## Scenario
A fictional Riyadh Metro exercise stores seat numbers in an unsorted list.

## Input
N (1–10), then N seat numbers (1–999).

## Important points
- **Use one-dimensional arrays** and the requested approach.
- Use **Arrays.sort(array)** to sort ascending, then print them in one line.
- Validate sizes and values before processing.
- Print the exact message and formatting shown.

## Sample input
```text
5
9 2 7 1 3
```

## Expected output
```text
1 2 3 7 9
```

## Boundary tests
