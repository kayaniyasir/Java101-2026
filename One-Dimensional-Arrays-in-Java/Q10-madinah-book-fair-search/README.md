# Question 10 — Madinah Book Fair Search

**Main concept:** Linear search

## Scenario
A book fair stores a small list of numeric book IDs and needs to check whether one is present.

## What you need to do
N (1–10), then N IDs (1–9999), then target ID (1–9999).

## Important points
- **Use a one-dimensional array** and the required operation.
- Use **linear search**, print **Found at index X** for the first match or **Not found**. Indexing starts at zero.
- **Validate the input limits** before processing or printing results.
- Print exactly the messages shown, including spaces and capitalization.

## Sample input
```text
4
15 25 35 25
25
```

## Expected output
```text
Found at index 1
```

## Boundary and extra tests
First item match; duplicate IDs; absent target.
