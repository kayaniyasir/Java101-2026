# Question 15 — Diriyah Museum Daily Counts

**Main concept:** Count below average

## Scenario
A Diriyah museum wants to know how many daily visitor counts were below the period average.

## Input
N (1–10), then N visitor counts (0–1000).

## Important points
- **Use one-dimensional arrays** and the requested approach.
- Calculate the **average**, then count values **strictly below average**; print the count.
- Validate sizes and values before processing.
- Print the exact message and formatting shown.

## Sample input
```text
4
10 20 30 40
```

## Expected output
```text
Below average: 2
```

## Boundary tests
All equal -> 0; one value -> 0; negative -> invalid.
