# Question 22 — Jeddah Beach Cleanup Total

**Main skill:** Array passed to method

## Scenario
A Jeddah cleanup team measures bags of litter collected over several days.

## Required input
N (1–10), then N bag counts (0–100).

## Important rules
- **Use one-dimensional arrays**, not multiple separate variables for the values.
- Write **static int sum(int[] values)** that returns the total; call it from main.
- Handle invalid sizes and out-of-range values as described.
- Show the exact sample output format.

## Sample input
```text
4
3 2 5 4
```

## Expected output
```text
Total bags: 14
```

## Boundary tests
All zeros → 0; invalid negative.
