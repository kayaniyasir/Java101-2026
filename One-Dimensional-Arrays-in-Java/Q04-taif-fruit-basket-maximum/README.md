# Question 04 — Taif Fruit Basket Maximum

**Main concept:** Find maximum

## Scenario
A Taif fruit seller weighs N baskets and needs the heaviest weight.

## What you need to do
N (1–10), followed by N integer weights (0–100 kg).

## Important points
- **Use a one-dimensional array** and the required operation.
- Find the **maximum value** with a loop; do not sort.
- **Validate the input limits** before processing or printing results.
- Print exactly the messages shown, including spaces and capitalization.

## Sample input
```text
4
4 9 6 7
```

## Expected output
```text
Maximum: 9 kg
```

## Boundary and extra tests
N=1; all equal; weight above 100.
