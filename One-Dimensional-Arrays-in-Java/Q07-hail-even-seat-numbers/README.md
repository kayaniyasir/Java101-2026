# Question 07 — Hail Even Seat Numbers

**Main concept:** Even and odd counts

## Scenario
A Hail school assigns positive seat numbers to participants.

## What you need to do
N (1–20), followed by N positive integers (1–999).

## Important points
- **Use a one-dimensional array** and the required operation.
- Count **even** and **odd** elements in the array.
- **Validate the input limits** before processing or printing results.
- Print exactly the messages shown, including spaces and capitalization.

## Sample input
```text
5
1 2 3 4 6
```

## Expected output
```text
Even: 3
Odd: 2
```

## Boundary and extra tests
All even; all odd; invalid zero.
