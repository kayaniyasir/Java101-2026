# Question 01 — Riyadh Exam Marks

**Main concept:** Array input and output

## Scenario
Read N exam marks and print them in the same order.

## What you need to do
N (1–10), followed by N integer marks (0–100).

## Important points
- **Use a one-dimensional array** and the required operation.
- Print the values separated by one space.
- **Validate the input limits** before processing or printing results.
- Print exactly the messages shown, including spaces and capitalization.

## Sample input
```text
3
70 85 90
```

## Expected output
```text
70 85 90
```

## Boundary and extra tests
N=1; invalid N; marks 0 and 100.

## Solution
Try the question before opening [ArrayQuestion01.java](ArrayQuestion01.java).

javac ArrayQuestion01.java
