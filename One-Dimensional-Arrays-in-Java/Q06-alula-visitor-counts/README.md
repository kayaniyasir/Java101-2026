# Question 06 — AlUla Visitor Counts

**Main concept:** Count above threshold

## Scenario
An AlUla exhibition records visitor counts for N days.

## What you need to do
N (1–10), then N counts (0–10000).

## Important points
- **Use a one-dimensional array** and the required operation.
- Count how many days had **more than 100** visitors; exactly 100 does not count.
- **Validate the input limits** before processing or printing results.
- Print exactly the messages shown, including spaces and capitalization.

## Sample input
```text
5
90 110 100 150 70
```

## Expected output
```text
Busy days: 2
```

## Boundary and extra tests
All 100 -> 0; exactly 101 -> counts; negative -> invalid.
