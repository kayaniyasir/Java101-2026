# Question 03 — Dammam Temperature Average

**Main concept:** Average calculation

## Scenario
A weather club records the temperature for N days in Dammam.

## What you need to do
N (1–7), followed by N integer Celsius values (-20 to 60).

## Important points
- **Use a one-dimensional array** and the required operation.
- Store values in an array; print their arithmetic average to one decimal place.
- **Validate the input limits** before processing or printing results.
- Print exactly the messages shown, including spaces and capitalization.

## Sample input
```text
3
20 22 24
```

## Expected output
```text
Average: 22.0 C
```

## Boundary and extra tests
N=1; negative temperatures; N=0.
