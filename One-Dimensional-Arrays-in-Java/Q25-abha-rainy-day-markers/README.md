# Question 25 — Abha Rainy Day Markers

**Main skill:** Boolean flags array

## Scenario
An Abha school records whether it rained on each day using 1 for yes and 0 for no.

## Required input
N (1–10), then N flags (0 or 1).

## Important rules
- **Use one-dimensional arrays**, not multiple separate variables for the values.
- Store flags in an **int[]** and count the rainy days (values equal to 1).
- Handle invalid sizes and out-of-range values as described.
- Show the exact sample output format.

## Sample input
```text
5
1 0 1 1 0
```

## Expected output
```text
Rainy days: 3
```

## Boundary tests
All dry; all rainy; flag 2 invalid.
