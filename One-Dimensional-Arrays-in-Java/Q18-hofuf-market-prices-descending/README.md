# Question 18 — Hofuf Market Prices Descending

**Main concept:** Sort descending

## Scenario
A Hofuf market wants its listed integer prices shown from highest to lowest.

## Input
N (1–10), followed by N prices (0–10000).

## Important points
- **Use one-dimensional arrays** and the requested approach.
- Use **Arrays.sort()** ascending, then print the array **from last to first**.
- Validate sizes and values before processing.
- Print the exact message and formatting shown.

## Sample input
```text
4
20 50 10 30
```

## Expected output
```text
50 30 20 10
```

## Boundary tests
Duplicate prices; all zero; invalid negative.
