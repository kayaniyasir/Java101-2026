# Question 13 — Najran Quiz Score Boost

**Main concept:** Modify all elements

## Scenario
A Najran class gives a bonus of five marks to each student, capped at 100.

## Input
N (1–10), followed by N marks (0–100).

## Important points
- **Use one-dimensional arrays** and the requested approach.
- Update every array element: **min(mark+5,100)**; print all updated marks.
- Validate sizes and values before processing.
- Print the exact message and formatting shown.

## Sample input
```text
3
93 98 60
```

## Expected output
```text
98 100 65
```

## Boundary tests
95 becomes 100; 100 stays 100; invalid mark.
