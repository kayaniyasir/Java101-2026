# Question 05 — Abha Hiking Minimum Time

**Main concept:** Find minimum

## Scenario
A hiking group compares how long participants took to finish a route in Abha.

## What you need to do
N (1–10), followed by N times in minutes (1–300).

## Important points
- **Use a one-dimensional array** and the required operation.
- Find **minimum time**, without sorting.
- **Validate the input limits** before processing or printing results.
- Print exactly the messages shown, including spaces and capitalization.

## Sample input
```text
4
56 48 60 51
```

## Expected output
```text
Fastest: 48 minutes
```

## Boundary and extra tests
One participant; equal times; time 0 invalid.
