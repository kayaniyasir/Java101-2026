# Question 14 — Jubail Training Attendance

**Main concept:** Compare two counts

## Scenario
Two Jubail training sessions recorded attendance. Decide which had more.

## Input
N (1–10), followed by N morning counts (0–100), then N evening counts (0–100).

## Important points
- **Use one-dimensional arrays** and the requested approach.
- Store **two 1D arrays**, total each one, print **Morning**, **Evening**, or **Equal**.
- Validate sizes and values before processing.
- Print the exact message and formatting shown.

## Sample input
```text
3
5 6 4
2 8 3
```

## Expected output
```text
Morning
```

## Boundary tests
Equal totals; all zeros; negative counts.
