# Question 12 — Jazan Mango Inventory Copy

**Main concept:** Copy an array

## Scenario
A Jazan farmer needs a separate copy of the harvested-box counts.

## Input
N (1–10), then N box counts (0–1000).

## Important points
- **Use one-dimensional arrays** and the requested approach.
- Create a **new array**, copy every element with a loop, and print the copy.
- Validate sizes and values before processing.
- Print the exact message and formatting shown.

## Sample input
```text
4
2 5 3 7
```

## Expected output
```text
Copied: 2 5 3 7
```

## Boundary tests
One element; all zeros; negative box count.
