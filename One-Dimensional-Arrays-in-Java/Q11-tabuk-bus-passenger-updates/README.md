# Question 11 — Tabuk Bus Passenger Updates

**Main concept:** Update array element

## Scenario
A Tabuk bus records passenger counts across its stops. One stop reports a corrected count.

## Input
N (1–10), N counts (0–100), then zero-based index (0 to N-1) and replacement count (0–100).

## Important points
- **Use one-dimensional arrays** and the requested approach.
- **Replace one array value** and print the complete updated array.
- Validate sizes and values before processing.
- Print the exact message and formatting shown.

## Sample input
```text
3
5 8 7
1 9
```

## Expected output
```text
5 9 7
```

## Boundary tests
Index 0; last index; out-of-range index.
